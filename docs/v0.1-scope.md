# Version 0.1 support scope

Household AI 0.1 documents and automates the smallest deployment that has been
tested end to end. A platform is not promoted to supported merely because an
underlying runtime can compile on it.

## Support levels

| Level | Meaning |
| --- | --- |
| Verified | Repeated on the reference hardware with documented evidence |
| Expected | Uses the same operating-system and accelerator path, but lacks a reference run |
| Experimental | Tooling may work, but maintainers do not yet provide an acceptance test |
| Unsupported | Outside the current installation and testing commitment |

## Initial matrix

| Platform | Benchmarking | Inference | Control plane | Status |
| --- | --- | --- | --- | --- |
| Apple Silicon macOS, 24 GB | MLX and llama.cpp Metal | Yes | Optional | Verified |
| Ubuntu 24.04, AMD Radeon 780M | llama.cpp Vulkan | Yes | Yes | Verified |
| Other Apple unified-memory sizes | MLX and llama.cpp Metal | Expected | Optional | Expected |
| Similar Ubuntu AMD systems | llama.cpp Vulkan | Expected | Yes | Expected |
| Windows | No v0.1 workflow | No v0.1 workflow | No | Unsupported |
| NVIDIA and Intel accelerators | No v0.1 workflow | No v0.1 workflow | No | Roadmap |

The benchmark harness may run on unlisted hardware, but an incidental successful
run does not expand the support promise.

## Included outcome

A successful installation should provide:

1. a recorded inventory for each participating computer;
2. reproducible performance measurements for compatible candidates;
3. chat, coding, and independent-judgment evaluation evidence;
4. a recommendation that explains memory fit and operational trade-offs;
5. an OpenAI-compatible inference endpoint;
6. a multi-user web interface with optional private web search;
7. private network access without public ingress; and
8. documented health, restart, backup, and rollback checks.

## Deferred work

- Windows inference nodes
- NVIDIA CUDA and Intel GPU-specific automation
- Home Assistant tools
- wake words, speech recognition, and voice satellites
- email, calendar, shopping, and other external-account tools
- automatic operating-system installation or repartitioning
- unattended authentication, firewall, or VPN changes

These items should be added one independently testable integration at a time.
